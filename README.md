# 📄 RAG Document Q&A

Ask questions about any PDF and get answers with page citations.

🚀 **Live Demo:** [Click here](https://rag-document-app-b38xffdguamazzrketgxh6.streamlit.app/)

## Tech Stack
- LangChain — RAG pipeline
- FAISS — vector storage
- HuggingFace `all-MiniLM-L6-v2` — embeddings (runs locally)
- Groq (Llama 3) — LLM for answering
- Streamlit — UI

## How it works
1. Upload any PDF
2. Ask questions in natural language
3. Get answers with exact page citations
